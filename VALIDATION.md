## PRD sections to amend

Ordered by how much they change the build.

1. **Component 3 (hooks).** Matcher `Edit|Write` (drop `MultiEdit`); expect N consecutive `Edit` events for a multi-edit change. `post_edit` can read `tool_response.filePath` and `structuredPatch` instead of shelling out to `git diff`. `pair hook prompt` must finish under 30 s (default for `UserPromptSubmit`), never exit 2, and emit `hookSpecificOutput.additionalContext`. Note that timed-out hook output is discarded silently.
2. **Component 2 (`pair mcp`).** Add the cancellation contract: Escape cancels `ctx` within ~100 ms, the server and its children survive, late results are dropped; `narrate`/`ask` select on `ctx.Done()` and kill `say`/`rec`/`whisper-cli` with SIGTERM (SIGKILL leaves a WAV header whisper hallucinates on). Apply the 400-char reject to `ask` too, and put "max 400, aim under 200" in both tool descriptions (schemas are deferred, so descriptions are what the model searches). Decide "(no answer)" from the audio before whisper (no file, < 0.3 s, RMS below threshold, cap fired) and add a hallucination blocklist ("Obrigado", "Legendas", "Transcrição", "Amara.org", "Tchau", lone "."). Trim whisper stdout (leading blank line and space); `-np` still writes ~40 ggml/Metal lines to stderr.
3. **Component 4 (`pair.nvim`).** Add a `FileChangedShell` autocmd (`v:fcs_choice = 'reload'` when unmodified; on conflict set it to `''` and `vim.notify`) so `checktime` never opens the modal dialog. `show()` must receive absolute paths. Fallback is `nvim --server … --remote-expr "luaeval(...)"`, never `--remote-send`. Restrict Go usage of go-client to `Dial`, `ExecLua`, `Command`, `Close` (the rest hit deprecated 0.12 API) and put a per-call deadline in `internal/nvim` since go-client has no per-call context.
4. **Configuration.** `PAIR_SOCK` default must be ≤ 104 bytes: `$TMPDIR/pair-<repohash>.sock` (or `127.0.0.1:<port>`), not `<repo>/.pair/nvim.sock`; `pair doctor` checks the length. Rewrite the Timeouts paragraph: 28 h is `MCP_TOOL_TIMEOUT`'s default, 30 min is the stdio *idle* timeout, and the 2-minute auto-background is real in 2.1.282 (`CLAUDE_CODE_DISABLE_BACKGROUND_TASKS=1` is a broader documented alternative). Replace the "16 chars/s" pacing assumption with ~15.
5. **Voice.** `pair doctor`: say Luciana is the basic voice and point to "Luciana (Enhanced)" in Manage Voices (no Premium/Siri pt-BR voice is exposed to `say`); run a 1 s `rec … trim 0 1` with a 10 s SIGTERM cap and, if no file appears, print the Microphone privacy-settings instructions (`tccutil reset Microphone <bundle>` as a reset); report ambient RMS and warn above 1 % (the silence stop would never fire). Replace `timeout 60` with a Go context (`timeout(1)` does not exist on macOS). Note that a 1.0 s pause does not stop recording, only ≥ 1.5 s. Test fixtures can come from `say -v Luciana --file-format=WAVE --data-format=LEI16@16000`, no sox needed. Vocabulary prompt helps partially (fixed Sidekiq and "model", not Hotwire or "migration").
6. **`CLAUDE.md` block.** Narrate rule: "Before each change, call `narrate` with one or two short sentences (under about 200 characters, about 10 seconds of speech). One narration may cover several related edits to the files it names." Ask rule: "One `ask` per decision point, recommended option first; if several small questions come up, ask the most consequential and put the rest under Open questions with your default." Add "Write PAIRING.md in the language you speak" (Sonnet wrote it in English) and "End the turn with one `narrate` saying what changed and what to look at" (typed summaries are never spoken).
7. **Installation / distribution.** `brew install whisper.cpp`; cask dependency names `whisper.cpp`, `sox`, `tmux`, `neovim`; goreleaser `homebrew_casks:` (snippet in `validation/item6-packaging.md`) with git-delta and Hammerspoon in `caveats` (cask DSL has no optional deps) and a quarantine-stripping post-install hook or notarization. lazy.nvim: `config = function(p) vim.opt.rtp:append(p.dir .. "/nvim") … end` or a separate `pair.nvim` repo. Replace "Homebrew bottle" with "pre-built binaries in a tap". `pair init` registers the server with `os.Executable()` (absolute path; a bad path surfaces as a misleading `ENOENT … posix_spawn 'stdio'`).
8. **Component 1 (`pair start`) and Component 6 (interrupt).** tmux: `split-window -h -l 50%` then `split-window -v -l 30% -t pair:0.1`, `new-session -d -x/-y` when not attached, `has-session` for idempotence; handle the workspace-trust dialog (default is "No, exit"). Interrupt: `tmux send-keys -t pair:0.0 Escape` (never `C-c`), wait ~0.3 s, then `send-keys -l -- "$transcript"` followed by a separate `send-keys Enter`.
9. **Risks table.** Replace "character cap" as the pacing mitigation with a length target in the prompt plus `Stop`-hook speech stats; add: `ask` length and back-to-back asks; Gatekeeper/quarantine on unsigned binaries; socket path length; go-client staleness; deferred MCP schemas (`pair doctor` runs a one-turn `narrate` probe); whisper hallucination on silence; mic permission dialog on first run.
10. **Open questions.** `show` auto-narrate: no (every `show` was followed within 0.7–2 s by a narrate or ask; a tick sound at most). Name: keep `pair` (no collision on Homebrew, PATH or man; `pairvoice` / `pairtty` are free fallbacks). `PAIRING.md` location: still open, no evidence either way.
11. **Validation plan / README.** Nested Claude Code sessions need `env -u CLAUDECODE` and `-p` wants `< /dev/null`; Claude Code blocks a bare foreground `sleep` in Bash and may auto-background long shell commands, so blocking-call tests need an MCP tool or a wrapper script; macOS has no `timeout`.
